# ♪ Music Land

เกมผจญภัยออนไลน์แนว Ragnarok Online ธีมดนตรี เล่นบนเว็บ ผู้เล่นหลายคนเห็นกัน ตีมอนสเตอร์ตัวเดียวกัน และรุมบอสด้วยกันได้

| ส่วน | ใช้อะไร | วางที่ไหน |
|---|---|---|
| หน้าเว็บ (ภาพ 3D, เมนู) | Three.js + TypeScript + Vite | **Cloudflare Pages** |
| เซิร์ฟเวอร์เกม (มอนสเตอร์, การต่อสู้, ผู้เล่นหลายคน) | **Colyseus** (Node.js) | Render / Fly.io / VPS / Colyseus Cloud |
| บัญชีผู้เล่นและเซฟ | **Supabase** (Auth + Postgres) | Supabase |

โลก 3D แบบ cel-shading (ลายเส้นการ์ตูน) สร้างด้วยโค้ดทั้งหมด (`src/three/`) ไม่มีไฟล์ลิขสิทธิ์ของใคร กล้องมุมสูงแบบ RO: คลิกขวาลากเพื่อหมุน ล้อเมาส์เพื่อซูม

## มีอะไรในเกม

- **2 แผนที่**: เมืองเมโลเดีย (ร้านค้า แผงตลาด น้ำพุ ครูเพลงฟื้นพลัง ไกด์) และทุ่งเมโลดี้ (มอนสเตอร์) เดินเข้าวงแหวนวาร์ปเพื่อข้ามแผนที่
- **สร้างตัวละคร** 3 ช่องต่อบัญชี เลือกเพศ ทรงผม 6 แบบ สีผม 8 สี หน้าตา 4 แบบ และ 5 อาชีพ:
  **นักร้อง** (ไมค์), **มือกีตาร์** (กีตาร์), **มือกลอง** (ไม้กลอง 2 มือ), **มือเบส** (เบส), **มือคีย์บอร์ด** (คีย์บอร์ด)
- **มอนสเตอร์ 10 ชนิด** (Lv 1-14) + บอส **ราชาเสียงเพี้ยน** ใครตีเกิน 10% ของเลือดได้รางวัลเต็ม
- **Base Lv / Job Lv** แบบ RO: เลเวลขึ้นได้ Status Point (ค่าอัปสเตตัสแพงขึ้นตามค่าปัจจุบัน), Job Lv ขึ้นได้ Skill Point
- **สกิลอาชีพละ 4** (โจมตีเดี่ยว, วงกว้าง, บัฟ/ฮีล, ติดตัว) ลากไปใส่ปุ่มลัด F1-F9
- **หน้าต่างแบบ RO** ลากย้ายได้: Basic Info, Equipment/Status, Inventory (แท็บ ใช้ได้/สวมใส่/อื่นๆ), Skill Tree, Hotkey bar, Minimap, Chat (แท็บ), ร้าน NPC ซื้อ/ขาย
- อุปกรณ์ 4 ช่อง: อาวุธ ชุด หมวก (เห็นบนหัวตัวละคร) เครื่องประดับ, ระบบน้ำหนัก, Hit/Flee/Critical/Miss, ตัวเลขดาเมจเด้งแบบ RO
- **แลกเปลี่ยน** ไอเท็มและ Zeny ระหว่างผู้เล่น: คลิกผู้เล่น → ขอแลกเปลี่ยน → ใส่ของ → OK ทั้งคู่ → แลกเลย (ฐานข้อมูลทำทีเดียวทั้งก้อน กันของหาย/ปั๊มของ)

ปุ่มลัด: `Alt+Q` สถานะ, `Alt+E` ไอเท็ม, `Alt+S` สกิล, `F1-F9`/`1-9` ปุ่มลัด, `Insert` นั่ง, `Tab` แผนที่ย่อ, คลิกขวาลาก หมุนกล้อง, ล้อเมาส์ ซูม, `Enter` แชท, `Esc` ปิดหน้าต่าง, คลิกขวา ยกเลิกเล็งสกิล

## รันในเครื่อง

```bash
npm install
cd server && npm install && cd ..

npm run server          # เซิร์ฟเวอร์เกมที่ ws://localhost:2567
npm run dev             # หน้าเว็บ (อีกหน้าต่าง terminal)
```

- ไม่ใส่ Supabase ใน `.env.local` = เซฟตัวละครใน browser และเซิร์ฟเวอร์ใช้ฐานข้อมูลในหน่วยความจำ (เชื่อข้อมูลจาก browser **ห้ามใช้แบบนี้บนเซิร์ฟเวอร์จริง**)
- ใส่ครบ (Supabase + Colyseus) = แบบเดียวกับตอนเปิดจริง
- ต้องเปิดเซิร์ฟเวอร์เกมเสมอ (ค่าเริ่มต้น `ws://localhost:2567` เปลี่ยนได้ด้วย `VITE_COLYSEUS_URL`)

## 1) ตั้งค่า Supabase

1. เปิด **SQL Editor** วางไฟล์ `supabase/setup.sql` ทั้งไฟล์ แล้วกด **Run** (รันซ้ำได้)
2. **Authentication → Sign In / Providers → Email**: ถ้าอยากให้สมัครแล้วเล่นได้ทันที ให้ปิด *Confirm email*
3. จด 2 ค่าจาก **Project Settings → API Keys**:
   - `anon` / publishable key: ใส่ในหน้าเว็บได้ (เปิดเผยได้)
   - `service_role` / secret key: **ใส่เฉพาะที่เซิร์ฟเวอร์เกม ห้ามใส่ในหน้าเว็บ ห้าม commit ห้ามส่งในแชท**

> แก้ค่าเกม (ราคา, EXP, ดรอป, อาชีพ) ที่ `src/data/gamedata.json` แล้วรัน `npm run gen:seed` จากนั้นรัน `supabase/setup.sql` ใหม่

## 2) Deploy เซิร์ฟเวอร์เกม (Colyseus)

ตัวอย่างใช้ **Render** (มีแพ็กเกจฟรี แต่จะหลับถ้าไม่มีคนเล่น 15 นาที ตื่นช้าราว 1 นาที):

1. https://render.com → **New → Blueprint** → เลือก repo นี้ (ใช้ `render.yaml` + `Dockerfile` ให้อัตโนมัติ)
2. ใส่ `SUPABASE_SERVICE_ROLE_KEY` ในหน้า Environment ของ service
3. ได้ URL เช่น `https://music-land-server.onrender.com` ใช้เป็น `wss://music-land-server.onrender.com`

ที่อื่นก็ได้ ขอแค่รัน Docker หรือ Node 22 ได้และเปิด WebSocket ได้ (Cloudflare Pages รัน Colyseus ไม่ได้)

## 3) Deploy หน้าเว็บบน Cloudflare Pages

1. **Workers & Pages → Create → Pages → Connect to Git** เลือก repo นี้
2. Build command: `npm run build` · Build output directory: `dist`
3. Environment variables: `VITE_SUPABASE_URL`, `VITE_SUPABASE_ANON_KEY`, `VITE_COLYSEUS_URL` (เช่น `wss://music-land-server.onrender.com`)
4. Deploy (push เข้า `main` ครั้งต่อไปจะ deploy ให้เอง)

## กันโกง

- เซิร์ฟเวอร์ Colyseus เป็นคนคุมมอนสเตอร์ คำนวณดาเมจ เช็กระยะ/ความเร็วตี/ความเร็วเดิน และ HP ของทุกคน
- EXP เงิน ดรอป ยา และการตาย บันทึกผ่านฟังก์ชันในฐานข้อมูลที่ **เรียกได้เฉพาะเซิร์ฟเวอร์เกม** (service role)
- หน้าเว็บเรียกได้แค่เมนู: สร้างตัวละคร อัปสเตตัส/สกิล ซื้อ/ขาย สวมใส่ (ฐานข้อมูลเช็กเงื่อนไขทุกอย่างเอง)
- การแลกเปลี่ยนตรวจของ/เงินจริงบนเซิร์ฟเวอร์ และย้ายของในฐานข้อมูลแบบ transaction เดียว

## โครงสร้าง

```
src/data/gamedata.json   ค่าเกมทั้งหมด: อาชีพ ไอเท็ม มอนสเตอร์ สกิล จุดเกิด (ใช้ร่วมกันทั้งหน้าเว็บและเซิร์ฟเวอร์)
src/data/index.ts        สูตรสเตตัส/EXP/Hit/Flee แบบ RO
src/game/maps.ts         แผนที่เมือง+ทุ่ง, ประตูวาร์ป, หาเส้นทาง (ใช้ร่วมกับเซิร์ฟเวอร์)
src/three/models.ts      ตัวละคร 3D หัวโต (เพศ/ผม/สีผม/หน้า) เครื่องดนตรี หมวก มอนสเตอร์ + ท่าทาง
src/three/props.ts       พื้น ตึกโครงไม้ แผงตลาด น้ำพุ ต้นไม้ ประตูวาร์ป
src/three/World3D.ts     ฉากเกม 3D กล้อง การเดิน การตี สกิล เอฟเฟกต์ ชื่อ/ตัวเลขดาเมจ
src/ui/hud.ts            หน้าต่างแบบ RO ทั้งหมด + ร้านค้า + แลกเปลี่ยน
src/ui/screens.ts        ล็อกอิน เลือกตัวละคร สร้างตัวละคร
src/services/            Supabase, โหมดเซฟใน browser
server/src/MapRoom.ts    ห้องเกม Colyseus 1 ห้องต่อ 1 แผนที่: มอนสเตอร์ การต่อสู้ สกิล รางวัล แลกเปลี่ยน
server/src/db.ts         เซิร์ฟเวอร์คุยกับ Supabase
supabase/setup.sql       SQL ทั้งหมดสำหรับวางใน SQL Editor (รันซ้ำ/อัปเกรดจากเวอร์ชันเก่าได้)
```

## ไอเดียต่อยอด

ปาร์ตี้/วงดนตรีแชร์ EXP, เปิดร้านขายของเอง (vending) แบบ RO, แผนที่และดันเจี้ยนเพิ่ม, เควสต์, เพลงประกอบ, เปลี่ยนภาพเป็น sprite วาดมือจริง (ใส่ไฟล์แทน texture key เดิมได้เลย)
