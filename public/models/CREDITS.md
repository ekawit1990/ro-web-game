# Character models

AvatarSample A–V by pixiv VRoid Project / yomox9, from VRoid Hub.
Conditions on VRoid Hub: avatar use, commercial use, redistribution and alterations allowed; attribution not required.
Changes for the game: textures downscaled to 512 px (`tools/shrink_vrm.py`) and the files gzipped (`.vrm.gz`).

## VRoid Hub models (`hub_<VRoid Hub model id>.vrm.gz`)

27 models by siroihakumai (白い白米) and the author "あ", from VRoid Hub.
Conditions embedded in each file (VRoid Hub license): avatar use by everyone, personal commercial use, corporate
commercial use, redistribution and modification allowed; credit not required.
Changes for the game: textures downscaled to 512 px (`tools/shrink_vrm.py`) and the files gzipped (`.vrm.gz`).

Models whose conditions say **redistribution: disallow** are not included: a web game serves every model file to
each player, which counts as redistribution.

## School uniforms (`uniform_m.vrm.gz`, `uniform_f.vrm.gz`)

Built by `tools/make_uniform.py` from models listed above, with new shirt / blouse shells painted by the script:
- boy: AvatarSample_C by pixiv VRoid Project (jacket removed, gloves painted off, trousers recoloured);
- girl: VRoid Hub model 4782566278761081075 "26" by siroihakumai (sailor collar, tie, skirt and loafers), with the
  body of VRoid Hub model 4360835510799003378 by the same author.

Both licences allow modification and redistribution.
