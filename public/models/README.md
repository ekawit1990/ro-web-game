# โมเดลตัวละคร VRoid (.vrm)

ถ้าโฟลเดอร์นี้ไม่มี `models.json` เกมจะใช้ตัวละครที่สร้างจากโค้ดตามเดิม ถ้ามีไฟล์นี้ ตัวละครผู้เล่นและ NPC จะเปลี่ยนเป็นโมเดล VRoid อัตโนมัติ

## 1. ทำโมเดลใน VRoid Studio (ฟรี)
1. ดาวน์โหลด VRoid Studio: https://vroid.com/studio
2. สร้างตัวละคร ปรับหน้า ผม และชุดได้ตามชอบ
3. **สีผม:** ถ้าจะให้ผู้เล่นเลือกสีผมในเกมได้ ให้ทำผมเป็นสีอ่อน (ขาวหรือเทาอ่อน) เพราะเกมจะคูณสีทับ ถ้าอยากให้ผมเป็นสีที่ทำไว้ ให้ตั้ง `"tintHair": false`
4. อย่าใส่ไมค์หรือกีตาร์ในโมเดล เพราะเกมใส่เครื่องดนตรีตามอาชีพให้เอง

## 2. Export
1. กด Camera/Exporter แล้วเลือก Export as VRM (เลือก VRM 1.0 หรือ 0.x ก็ได้)
2. ลดขนาดไฟล์: ตั้ง Polygon reduction ประมาณ 15,000–30,000 และ Texture atlas resolution เป็น 1024 หรือ 2048 (ไฟล์ละ 5–15 MB โหลดเร็วกว่ามาก)
3. ตั้งชื่อไฟล์เป็นภาษาอังกฤษไม่มีเว้นวรรค เช่น `girl1.vrm`

## 3. ใส่ในเกม
1. วางไฟล์ `.vrm` ในโฟลเดอร์นี้ (`public/models/`)
2. คัดลอก `models.example.json` เป็น `models.json` แล้วแก้ชื่อไฟล์:
   - `m` คือรายชื่อโมเดลชาย และ `f` คือรายชื่อโมเดลหญิง
   - "ทรงผม" ที่เลือกตอนสร้างตัวละครจะเลือกโมเดลตามลำดับ (ทรงที่ 1 ได้ไฟล์แรก ทรงที่ 2 ได้ไฟล์ที่สอง และถ้าทรงผมมีมากกว่าจำนวนไฟล์ จะวนกลับไปไฟล์แรก)
   - ถ้ามีแค่เพศเดียว อีกเพศจะใช้โมเดลเดียวกัน
3. Build แล้ว deploy ขึ้น Cloudflare Pages ตามปกติ

## ลิขสิทธิ์
ใช้เฉพาะโมเดลที่คุณทำเองหรือที่ผู้สร้างอนุญาตให้ใช้ในเกมได้ (ดูเงื่อนไข VRM license ของโมเดลแต่ละตัว)

## ทดสอบโดยไม่มีโมเดลจริง
