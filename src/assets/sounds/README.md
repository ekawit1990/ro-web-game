# เสียงที่ใส่ได้ (ElevenLabs)

วางไฟล์ไว้ในโฟลเดอร์นี้ตามชื่อในตาราง (หรือใช้ `python3 tools/import_sounds.py <โฟลเดอร์หรือ zip>` ซึ่งจะบีบอัด ตัดเงียบ และปรับความดังให้).
